# Trinos en la oscuridad

**Trinos en la oscuridad** es un videojuego desarrollado en Godot Engine. El proyecto combina exploración, narrativa y elementos de rol en un entorno 2D.

## Resumen del Proyecto
- **Motor:** Godot Engine
- **Género:** Aventura/RPG 2D
- **Plataforma objetivo:** PC Win/ Web html5
- **Estado:** Versión inicial (kcoro_0.0.4)

## Características principales
- **Exploración de mundo abierto:** El jugador puede recorrer el entorno principal de prueba. puede recorrer distintos mapas, transicionando entre ellos.
- **Sistema de menús:** Incluye un menú principal y menús de usuario para gestionar la partida. donde despliega la informacion del jugador
- **Gestión de música y sonido:** controlador de música para cambiar entre temas según el estado del juego (menú, exploración, batalla).
- **Interacción con NPCs y objetos:** El jugador puede interactuar con personajes y elementos del entorno.
- **Sistema de batalla:** Incluye elementos de combate por turnos (to be refactored).
